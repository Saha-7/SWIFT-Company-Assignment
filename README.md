# Front-End Assignment

A React TypeScript dashboard application with comments management and user profile features.

## How to Run Locally

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Open browser at `http://localhost:5173`

## Features

- Comments dashboard with pagination, search, and sorting
- User profile page
- State persistence across page refreshes
- Fully responsive design
- TypeScript for type safety

## Tech Stack

- React 18
- TypeScript
- TailwindCSS
- React Router
- Vite
